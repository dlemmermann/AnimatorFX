# Security policy

## Supported versions

Security fixes target the latest stable release. Until the first stable release, use the latest
default-branch revision; older snapshots are not supported.

## Reporting a vulnerability

Do not disclose vulnerabilities, exploit details or sensitive files in public issues.
Use [GitHub private vulnerability reporting](https://github.com/dlemmermann/AnimatorFX/security/advisories/new)
when enabled. If it is unavailable, contact the maintainers privately through the
[DLSC contact page](https://www.dlsc.com/contact/).

Include affected versions, reproduction steps, expected impact and a minimal example without
credentials or third-party private information. Please allow time for investigation and a fix
before public disclosure. There is no guaranteed response time or bounty program.

Animation and import files can include large assets and exercise platform font, XML and media
parsers. Do not treat files from untrusted sources as harmless. Do not include passwords,
tokens or other confidential data in animations, bug reports or logs.
